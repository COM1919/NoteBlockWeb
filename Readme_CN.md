## ⬇ 在线体验 & 下载
本项目已部署并且任何人都可以访问。
直接访问：**https://webnbs.com**

为了摆脱浏览器的标题窗口，我们正在计划制作本地应用。

> _针对 电脑端 / 手机端 进行的体验优化_

## 🎵 功能说明
- 完整网页版NBS编辑器，使用标准 `.nbs` 文件格式
- QWERTY键盘实时演奏模式
- 支持 MIDI 文件导入与导出，并且所有数据都在本地进行
- 含有八度范围转化算法，在不大幅度失去听感的基础上，转换为我的世界音域内
- 更多 MIDI 自定义导入功能，你可以更好的转换 MIDI 文件
- 目前支持4个地区的语言，但目前由AI翻译，并不保证准确，也欢迎提交issues
