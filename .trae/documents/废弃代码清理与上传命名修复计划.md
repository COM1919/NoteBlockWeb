# 废弃代码清理与"上传"命名修复计划

## Context

用户反馈"还存在上传的代码，这会导致误会"。全面扫描 `src/` 后确认三处需处理：

1. **upload-progress 进度弹窗命名误导**：代码把一套"处理进度"弹窗命名为 `upload-progress`/`showUploadProgress`，看起来像有"上传"功能。实际它是**活跃功能**（[main.js](file:///d:/软件开发项目/NoteBlockWeb/src/static/js/main.js) 中打开/保存/导出 NBS、打包/导入 zip 等 10+ 处调用），只是命名错误。
2. **孤儿函数 `_uploadWithProgress`**：在 [api_client.js](file:///d:/软件开发项目/NoteBlockWeb/src/static/js/api_client.js#L27) 定义，全项目**零调用**，是真正废弃代码。
3. **FLS 模块完全废弃**：经确认，`toggleFLSMode()` 只有定义无一调用，`state.flsEnabled` 恒为 `false` 且永不可能被置为 `true`，所有 `if (state.flsEnabled && ...)` 分支均为死代码，**没有任何用户入口能进入 FLS 模式**。FLS 是一个完整的废弃功能残留。

清理范围：仅高置信度废弃（用户要求，控制风险）。
