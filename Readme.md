## ⬇ Websites & Download
The service is publicly available for everyone.
Visit the online editor directly: **https://webnbs.com**

We are planning native desktop clients to eliminate browser window limitations.

> _Optimized for both desktop and mobile devices._

## 🎵 Features
- Fully featured web-based NBS editor, compatible with standard `.nbs` file format
- QWERTY keyboard real-time performance mode
- MIDI import & export support. All file processing happens locally on your device
- Octave conversion algorithm: transpose music into Minecraft note block range with minimal audible quality loss
- Advanced MIDI import options for easier conversion of MIDI compositions
- Supports 4 languages. Translations are AI-generated and may contain inaccuracies. Issues for translation improvements are welcome.

The project receives ongoing updates and improvements.

The FLS mode was abandoned at an early stage of development. Modifications are not planned in the short term due to deep dependencies within core logic.
